# 07 — News / Berita

Rich-text article management. The richest view in the app: filters, Quill editor, inline media upload, category collection.

---

## 1. Purpose

CRUD for village news articles. Articles have a title, slug (auto?), rich-text body, cover image, category, and publication date. Body can include inline images and videos.

## 4. API Endpoints

| Method | Path | Body / Params | Used by |
|--------|------|---------------|---------|
| `GET`    | `/berita?page&limit&search&date_from&date_to&category` | —                  | List view |
| `GET`    | `/berita/{id}`                                            | —                  | Form view (edit) |
| `POST`   | `/berita`                                                 | multipart `FormData` | Form view (create) |
| `PUT`    | `/berita/{id}`                                            | multipart `FormData` | Form view (edit) |
| `DELETE` | `/berita/{id}`                                            | —                  | List view (delete) |
| `POST`   | `/berita/upload-media`                                    | multipart `FormData` (field `file`, `type`) | Quill image/video handlers |
| `GET`    | `/public/berita/categories?page&limit&q`                 | —                  | Form view (datalist) + CategoryManagerModal |
| `POST`   | `/berita/categories`                                      | `{ name }`         | CategoryManagerModal (create) |
| `DELETE` | `/berita/categories/{id}`                                 | —                  | CategoryManagerModal (delete) |

Public endpoints (`/public/berita/...`) and `/berita/categories` are defined in swagger but not used by the admin frontend.

## 6. Behaviors

### 6.1 List (`NewsListView.vue`)

- Filter row (above table):
  - Search input (debounced 300 ms → `?search=`).
  - Date-from / date-to inputs (HTML `<input type="date">` → `date_from` / `date_to`).
  - Category dropdown — populated **client-side** from the unique categories seen across loaded pages (since `/berita/categories` is not consumed by the admin).
- Table columns: Cover (thumbnail) | Judul | Kategori | Tanggal | Aksi.
- Pagination via `pagination.total_pages`.

### 6.2 Form (`NewsFormView.vue`)

- Mode from `route.name`.
- Fields:
  - `title` — required.
  - `category` — free-text `AppInput` with a `<datalist>` autocomplete sourced from `/public/berita/categories`, plus a `Kelola Kategori` button that opens the reusable `CategoryManagerModal`. Internally the field is `{ id, name }`; the form binds `name` for display and resolves `id` from the suggestions or auto-creates a new category on submit. Backend receives `category: <UUID>` in FormData per swagger.
  - `cover_image` — required on create; shows existing thumbnail with replace on edit.
  - `body` — `RichTextEditor` (Quill).
  - `publication_at` — optional date input.
- `RichTextEditor`:
  - Uses Quill 2 with `quill-better-table-plus`.
  - Image / video buttons open a file picker → upload via `newsService.uploadMedia` → insert the returned URL at the cursor.
- Submit builds `FormData` and posts/puts.

### 6.3 Delete

- Confirm dialog → `DELETE /berita/{id}`.

## 7. UI Notes

- The form page is taller than other form pages because of the Quill editor.
- `RichTextEditor` applies its own Tailwind typography styles so the Quill output renders consistently.
- The editor is not localized (Quill toolbar is English).

## 8. Notes & Gotchas

- **Categories are collected client-side** by accumulating seen categories across pages — if a category exists only on a page the user has not loaded, it will not appear in the filter. Consider using `/berita/categories` from swagger.
- **`/berita/upload-media`** returns the URL the editor inserts directly. Confirm the response shape.
- **Slugs** are not editable in the UI — if the backend does not generate one, this will be a bug.
- **No draft / publish toggle** — there is no `published` boolean. Articles become visible (or not) by other backend logic (probably `publication_at`).
- **Tags** are declared in swagger but the form does not currently expose them.
- **`publication_at`** is optional in the form but may be required by the backend — verify.
